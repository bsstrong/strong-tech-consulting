# Strong Tech Consulting Notes

A working repository for project notes, planning, personal ideas, and uncategorized thoughts.

## Structure

- [`random/`](random/) — unclassified thoughts and an inbox for ideas that may move elsewhere later.
- [`planning/`](planning/) — plans and decisions that span projects or the business.
- [`projects/`](projects/) — notes organized by project.
- [`personal/`](personal/) — personal notes kept separately from project work.

Use Markdown files with descriptive, kebab-case names. Add a date prefix (`YYYY-MM-DD-`) when chronology matters.
